# Sistema de Monitoramento Hidrológico - Desafio Cogmo

Projeto desenvolvido em Python e Django REST Framework para o teste técnico da Cogmo. O objetivo do sistema é monitorar estações, rios e volume de chuvas.

O projeto inclui:
- API REST para consultar os dados.
- Script em Python para gerar os dados de teste (seed) e salvar em CVS.
- Documentação dos endpoints criada com `drf-spectalular` (Swagger/Redoc).

---

## Tecnologias Usadas

- Python
- Django & Django REST Fremework
- SQLite
- drf-spectacular
